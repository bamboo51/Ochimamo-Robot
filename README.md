# Ochimamo-Robot: 作業者安全システム

このシステムは、BLE（Bluetooth Low Energy）を使用して、ロボットとの衝突や危険区域への侵入から作業者を守ります。

## アーキテクチャ: ブロードキャスト & 三点測位

以前の1対1接続モデルから、複数の作業者を同時に保護できる**ブロードキャストモデル**に移行しました。

### 1. ロボット側 (Raspberry Pi)
-   **役割**: 灯台 (ブロードキャスター)
-   **機能**: LiDARを使って壁との距離を監視します。もし人が壁に挟まれそうになった場合、その特定の作業者IDに対して「危険」信号を発信（ブロードキャスト）します。
-   **技術**: ROS 2, Python `bless`

### 2. 作業者側 (M5Stack)
-   **役割**: 見張り番 (スキャナー)
-   **機能**:
    1.  **壁ピンチ警報**: ロボットからの信号を常に監視します。「壁が近い」という信号を受信すると、最優先で警報を鳴らします。
    2.  **エリア警報**: 設置された3つのBLEアンカーを使って位置を計算（三点測位）します。もし地図上の「危険エリア（赤）」に入ると警報を鳴らします。
-   **技術**: C++, NimBLE, M5Unified

## インストール方法

### A. Raspberry Pi (ロボット)
1.  **依存ライブラリのインストール**:
    ```bash
    pip install bless
    ```
2.  **ノードの実行**:
    ```bash
    ros2 run ble_warn ble_warn
    ```

### B. M5Stack (作業者)
1.  **ハードウェア設定**:
    -   部屋に3つのBLEアンカー（ビーコン）を設置してください。
    -   `m5stack/Positioning.h` ファイル内のMACアドレスを、実際のアンカーのものに更新してください。
2.  **地図設定**:
    -   `m5stack/SafetyUI.h` ファイルで安全・危険エリアを定義してください。
3.  **作業者ID設定**:
    -   各M5Stackごとに、`m5stack/main.cpp` の `#define MY_TRACK_ID X` を書き換えてください。
4.  **書き込み**:
    -   PlatformIO または Arduino IDE を使って書き込んでください。

## 画面の見方 (M5Stack)

| 画面 | 意味 | アクション |
| :--- | :--- | :--- |
| **赤 (WALL ALERT)** | ロボットがあなたを壁際に追い詰めています。 | **直ちに離れてください** |
| **赤 (ZONE ALERT)** | 侵入禁止エリアに入っています。 | 安全な場所に移動してください。 |
| **地図 (水色の点)** | 安全です。現在の自分の位置を表示しています。 | なし |
| **黄色文字** | Searching for Anchors... (アンカー探索中) | エリア内に移動してください。 |

## トラブルシューティング
-   **反応が遅い？**: M5Stackは0.2秒ごとにスキャンしています。もしロボットの反応が遅い場合は、LiDARやROSノードの遅延を確認してください。
-   **画面がチカチカする？**: ダブルバッファリング（スプライト機能）を使用しているため、ちらつき（フリッカー）はありません。
-   **位置が飛び跳ねる？**: 3つのアンカーがしっかり見えているか確認してください。移動平均フィルタでジッターを抑えていますが、BLEは金属や水分（人体）の影響を受けやすいため、多少の誤差は発生します。
